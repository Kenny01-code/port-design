# RenderVision

Responsive React + TypeScript portfolio landing page, built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The original motion frames are stored as WebP files in `public/frames`. Pushes to `main` build and deploy the production site to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.
